# PAS IT HelpDesk WhatsApp – Public Privacy Pages

Privacy policy and data-deletion instructions for the PAS IT HelpDesk WhatsApp integration provided by ProZone Middle East for General Trading WLL.

This repository contains:
- `index.html` – Privacy Policy
- `data-deletion.html` – Data Deletion Instructions
- `style.css` – Shared page styling

To publish publicly, enable GitHub Pages from **main / (root)** in the repository Settings → Pages.

Once GitHub Pages is enabled:
- Privacy policy: https://nenad-prozone.github.io/pas-whatsapp-privacy/
- Data deletion: https://nenad-prozone.github.io/pas-whatsapp-privacy/data-deletion.html

Please review the policy language with the relevant ProZone representative before relying on it as the organization's formal policy.
